Documento de componentes frontend

Proyecto: tienda virtual básica TecnoFácil

1. Introducción

El presente documento describe los componentes frontend definidos para TecnoFácil, una tienda virtual básica desarrollada como proyecto académico. La aplicación permite consultar productos tecnológicos, conocer el procedimiento de compra, seleccionar un artículo y registrar una operación. La interfaz se construye con HTML para la estructura, CSS para la presentación y JavaScript para las interacciones básicas.

2. Objetivo

Definir la estructura y los componentes frontend necesarios para construir una tienda virtual sencilla, organizada, comprensible, usable y adaptable a computadores, tabletas y teléfonos móviles.

3. Alcance del proyecto

La primera versión de TecnoFácil permitirá:

  • Consultar un tutorial de compra organizado mediante enlaces internos.
  • Mostrar productos con imagen, nombre, descripción, categoría y precio.
  • Filtrar productos por categoría utilizando JavaScript.
  • Seleccionar un producto y diligenciar los datos del comprador.
  • Calcular el total según el precio y la cantidad.
  • Guardar la compra mediante PHP y MySQL.
  • Consultar las compras registradas.

La aplicación no procesa pagos reales, no administra inventarios y no incluye un carrito con varios productos. Estas funciones quedan fuera del alcance para mantener un nivel básico.

4. Estructura de navegación

Inicio→Productos→Compra→Confirmación

El menú principal también permite ingresar directamente al tutorial, al documento de componentes y al listado de compras.

5. Elementos HTML definidos

ElementoUso dentro del proyecto
<header>Contiene el logotipo y el encabezado de cada página.
<nav>Organiza el menú de navegación principal y el índice del tutorial.
<main>Identifica el contenido principal de la página.
<section>Agrupa temas, productos y bloques relacionados.
<article>Representa cada tarjeta de producto y el contenido independiente.
<h1> a <h3>Establece una jerarquía clara de títulos.
<ol> y <ul>Presenta pasos ordenados y listas de características.
<a>Conecta páginas y permite desplazarse dentro del tutorial.
<img>Muestra el logotipo y las imágenes de productos.
<form>Reúne los datos necesarios para registrar la compra.
<input>Recibe nombre, documento, teléfono, correo y cantidad.
<button>Activa filtros, abre el menú y envía formularios.
<table>Presenta las compras guardadas en la base de datos.
<footer>Muestra información final y tecnologías utilizadas.

8. Principios de usabilidad y accesibilidad

  • Menú consistente en todas las páginas.
  • Textos claros, breves y escritos en lenguaje sencillo.
  • Contraste suficiente entre fondo, texto y botones.
  • Campos acompañados de etiquetas visibles.
  • Imágenes con texto alternativo.
  • Foco visible para la navegación con teclado.
  • Mensajes para estados vacíos, errores y confirmaciones.
  • Diseño adaptable sin desplazamiento horizontal innecesario.

9. Relación con el backend

PHP recibe los datos del formulario mediante POST, los valida y consulta el precio real del producto. Luego calcula el total y ejecuta una consulta preparada para guardar la compra. MySQL almacena los productos y las operaciones registradas.

10. Conclusión

La estructura definida permite desarrollar una interfaz funcional sin utilizar librerías o frameworks. Cada tecnología tiene una responsabilidad específica y el proyecto puede ampliarse posteriormente con inventario, autenticación o un carrito de compras.
